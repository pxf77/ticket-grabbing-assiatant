# 合规边界

## 本项目做什么

- 成都演出信息聚合。
- 官方开放接口或用户手动官方链接接入。
- 状态变化提醒。
- 开售倒计时。
- 官方购票页跳转。
- 手动购票 checklist。
- 失败复盘。

## 本项目不做什么

- 不自动登录票务平台。
- 不自动选择场次、票档或座位。
- 不自动提交订单。
- 不自动支付。
- 不识别或绕过验证码。
- 不绕过排队或风控。
- 不保存票务平台账号密码。
- 不保存完整身份证件信息。
- 不使用代理池、多账号池、Cookie 池。
- 不进行 App 私有接口逆向、Hook 或设备指纹伪装。

## 个人信息最小化

MVP 不需要采集观演人的姓名、身份证号或手机号。只保存：

- 订阅规则。
- 通知通道配置。
- 官方链接打开记录。
- 成功/失败复盘记录。

Webhook、Push endpoint 等敏感通道凭证在生产环境应加密存储，日志中只允许输出脱敏值。

## 代码守卫

根目录提供：

```bash
pnpm check:compliance
```

该脚本会扫描源码中是否出现若干越界实现信号。它不是完整安全审计，但可以作为 CI 的最低线。
